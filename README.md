# qbskill · 乔巴 Skill 工具箱

## 项目介绍

qbskill 是由乔巴开发和维护的 Skill 合集，专注于电商与内容创作，后续将持续收录和更新更多高质量、实用的 Skill。

大部分 Skill 以直接调用为目标；部分 Skill 内置对应的 ComfyUI 工作流，可通过 RunningHub（RH）调用云端算力，无需在本地部署 ComfyUI 或下载大型 AI 模型。

项目支持多个 Skill 集中管理、统一安装与持续更新。每个正式发布的 Skill 都有独立编号、版本信息和中文使用说明，并通过 B 站教学视频介绍具体操作和使用效果。

## 项目特点

- 聚焦电商与内容创作相关的实用 Skill。
- 部分 Skill 内置 ComfyUI 工作流，并通过 RunningHub 调用线上算力。
- 规划支持多个 Skill 的集中安装与持续更新。
- 使用统一的全局编号制度，每个 Skill 独立维护版本。
- 正式发布的 Skill 提供中文说明，并在发布时补充对应的 B 站教程。

## 分类与命名

- `qbds`：乔巴电商。
- `qbwl`：乔巴文旅。
- `qbgn`：乔巴功能。

Skill 名称采用“类别前缀-三位全局编号-功能拼音缩写”的格式，例如 `qbds-059-xqy`；用户界面与说明优先显示中文功能名。

所有分类共用一套全局递增编号，不按分类从 `001` 重新开始。一个编号只对应一个正式登记的 Skill；编号正式分配后不可重用，Skill 退役后仍保留登记。编号代表 Skill 身份，不是版本号，也不直接代表当前可用 Skill 数量。

每个 Skill 拥有独立版本号。一般升级保持名称不变，只有用途发生本质变化时才分配新编号。正式发布的 Skill 必须包含 `SKILL.md` 和简洁的中文 `README.md`。

## 安装与更新

项目今后将支持通过 Skills CLI 从 GitHub 一次安装整个 Skill 集合。由于目前尚未发布 Skill，安装能力和准确命令尚未验证；首个真实 Skill 发布后再完成验证并补充说明。

克隆本仓库后执行 `git pull` 只会更新本地仓库文件，不等同于更新 Agent 中已经安装的 Skill。正式更新方式将在有可安装 Skill 后另行说明。

## 云端使用条件

需要 RunningHub 的 Skill，由用户自行注册账号，并按照该 Skill 的说明完成必要的 API 访问配置、额度或费用准备。无需本地部署 ComfyUI 或下载大型 AI 模型，不代表云端调用永久免费或免配置。

请勿将 API Key、访问令牌或其他凭据提交到仓库。
